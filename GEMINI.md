# «Династия»: указатель для Gemini / Antigravity

Правила проекта лежат в других файлах, здесь только ссылки, чтобы они не разошлись:

1. `AGENTS.md`: краткие правила и порядок чтения.
2. `CLAUDE.md`: **основные правила проекта** (контент, формулы, дизайн, этапы).
3. `docs/AI-HANDOFF.md`: архитектура, дизайн-система, 3D-конвейер, навыки, грабли.
4. `docs/PARALLEL-WORK.md`: **как работать параллельно с Claude Code: своя ветка `ag/…`, своя папка, push в свою ветку, слияние в `main` через pull request.**

Работаете в ветке `ag/work`, в `main` напрямую не пушьте. Перед задачей: `git fetch origin && git merge origin/main`. Готовую работу отправляйте командой `node tools/ship.mjs` (сам вливает только изменения в `content/`, `docs/`, `public/art/`, остальное ждёт владельца).

**Важно:** курс заменён на таргетинг (Kaspi убран). Перед каждой задачей обязательно `git fetch origin` и `git merge origin/main`, иначе вы работаете со старым контентом. `graphify-out/` в git не добавлять, git-хук Graphify не ставить: `.git/hooks` общий для обеих папок.
