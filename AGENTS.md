# Инструкции для ИИ-агентов (Antigravity, Codex, Cursor и др.)

Проект «Династия»: игра-тренажёр на React + TypeScript + Vite (PWA, GitHub Pages). Интерфейс и контент на русском.

**Сначала прочитайте:**
1. `CLAUDE.md`: правила проекта (формулы только через свои парсеры, контент только в `content/*.json`, mobile-first 390px, стиль «тёмное золото»).
2. `docs/AI-HANDOFF.md`: полная сводка: архитектура, дизайн-система, 3D-конвейер, навыки и инструменты, грабли, что не доделано.
3. `SPEC.md`: полное ТЗ.

**Важно:** курс заменён на таргетинг (Kaspi убран). Перед каждой задачей обязательно `git fetch origin` и `git merge origin/main`, иначе вы работаете со старым контентом. `graphify-out/` в git не добавлять, git-хук Graphify не ставить: `.git/hooks` общий для обеих папок.

**Минимум правил:**
- Перед коммитом `npm run build` без ошибок; после правок контента `npm run validate`.
- Не пушить в GitHub без просьбы пользователя. Коммиты на русском.
- Не использовать `eval`/`new Function`. Не хардкодить цифры из контента.
- Все анимации учитывают `prefers-reduced-motion`. Проверять на ширине 390px и 1280px.
- Тяжёлые 3D-модели прогонять через `tools/optimize-models.mjs`; исходники в `Models/` в git не добавлять.

**Параллельная работа:** над проектом одновременно работают два агента (Claude Code и Antigravity). У каждого своя ветка и своя папка, оба пушат свои ветки, в `main` попадает только через pull request. Подробности и команды: `docs/PARALLEL-WORK.md`. Antigravity работает в ветке `ag/work` и отправляет работу командой `node tools/ship.mjs`: если изменены только `content/`, `docs/`, `public/art/` и проверка зелёная, скрипт сам вливает PR в `main`; всё остальное ждёт владельца.
