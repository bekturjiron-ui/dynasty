# Dynasty — игра-тренажёр комплексного таргетинга (Instagram/Meta + Telegram Ads, рынок Казахстан)
Исходное ТЗ: SPEC.md (игровая механика актуальна, тема Kaspi заменена курсом по таргетингу). Старый Kaspi-курс сохранён в git-метке `kaspi-course-v1`.
**Текущее состояние, как мы работаем и открытые хвосты: NOTES.md. Читай его первым в новом окне и обновляй в конце пачки правок.**
- Стек: React + TypeScript + Vite, Tailwind, Dexie, vite-plugin-pwa, Recharts.
- Без сервера и платных API. Деплой — GitHub Pages через GitHub Actions (.github/workflows/deploy.yml).
- Mobile-first: проверяй вёрстку на ширине 390px, safe-area для iPhone.
- Интерфейс на русском. Тёмная тема, золото #C9A227 на почти чёрном #0E0E10.
- Контент только в /content/*.json по схеме из src/content/schema.ts (zod). После правки контента: `npm run validate`.
- Формулы считай через src/lib/expr.ts (свой безопасный парсер), никогда через eval()/new Function.
  Пакет expr-eval из исходного ТЗ НЕ используем: у него критические уязвимости без исправления.
- Формулы в стиле Excel (тренажёр 5×5) считает src/lib/sheet.ts: ЕСЛИ, ВПР, ПРОСМОТРХ, СЧЁТЕСЛИ, СУММЕСЛИ, текст в кавычках (включая «умные» кавычки iPhone).
- Цифры в контенте не хардкодить: учебные офферы — в content/offers.json (o1…oN). В формулах доступны `o1.price`, `margin`, `clickToLead`, `leadToSale` и расчётные `profit`, `maxCac`, `maxCpl`, `maxCpc`.
- Типы заданий: число, таблица 5×5 (`sheet`), выбор (`choice`, ровно один верный, у каждого варианта `why`), текст объявления (`textCheck`, проверка в src/content/adCheck.ts, `sample` гоняет валидатор).
- Видео в уроке: `video` (youtubeId, start, end, focus, необязательный вопрос). Только встраивание открытых роликов через youtube-nocookie, по тапу; без сети урок проходится по тексту. Чужие ролики и транскрипты не скачиваем в репозиторий и не копируем в уроки.
- Ошибки игрока подавай как «доклад советника» в ₸, без слов «неверно», «ошибка», «плохо».
- После каждого этапа: npm run build без ошибок, коммит, краткий отчёт.

## Переговоры
- Узел: реплика NPC + 1–4 варианта; `effect.price` — п.п. скидки, `loyalty`/`patience` — сдвиг шкал 0…100.
  Скидку даёт ход, ведущий к уступке; реплики NPC показывают текущую цену через {{price|tg}} / {{discount|pct}}.
- Ниже `coldBelow` — похолодание; 3 холодных хода подряд — партнёр уходит. Сделка с холодным партнёром —
  скидка только на первое размещение, дальше замена дороже (`replacementMarkup`). XP — только за сделку с сохранёнными отношениями.
- Валидатор перебирает все состояния: нет вечных циклов, давление не выгоднее влияния, честная сделка достигает черты.

## Империя
- Постройки в content/empire.json: цена в Капитале + minRank (статус не покупается одним Капиталом).
  Покупка — buyBuilding() одной транзакцией; в серию дней не засчитывается.
- «Дом Вернеров» = XP игрока, закрывающего каждую неделю вовремя (rivalCurve). Растягивание плана (planOffsetWeeks) сдвигает и его.
- Валидатор проверяет, что по плану каждую постройку можно купить до 12 недели.

## Совет Дома
- Бриф проекта (Settings.project): средний чек, маржа, конверсии. Из него считаются цели и потолки CAC/CPL/CPC (src/game/diagnose.ts).
- Недельный отчёт кампании: расход, показы, охват, клики, заявки, продажи, выручка. Советник называет узкое место по дереву диагностики. +40 XP один раз за неделю плана.

## План и редактор
- Базовый план — content/plan.json; правки наставника — IndexedDB `plan` (effectiveContent в src/game/plan.ts).
  Экраны берут недели из `game.content`, НЕ из импорта `content` — иначе правки не видны.
- Week.n — позиция (меняется), Week.key — постоянный ключ (исходный номер; новые недели — от 101).
  Контракты, миссии и ranks.promoteWhen.contracts ссылаются на key. Никогда не сохраняй прогресс по n.
- Игрок меняет порядок уроков внутри недели без PIN; всё остальное — редактор под PIN (по умолчанию 0000).
- Запись правок хранит `baseWeeks` (базу на момент сохранения). rebaseWeeks накладывает на новую версию плана только то, что человек менял,
  поэтому новый контент доходит до игрока. Новым неделям в plan.json давай новый key, старые key не переиспользуй (1–26 принадлежали Kaspi-курсу).
- Правила рекламы перед написанием уроков сверяй с первоисточниками: Meta Advertising Standards (косметика: 18+, без идеализированных «до/после», без личных характеристик), ads.telegram.org/guidelines (160 знаков, ссылки на канал или бота), закон РК «Об онлайн-платформах и онлайн-рекламе» на adilet.zan.kz (маркировка рекламы блогеров). ОРД и erid — только для аудитории РФ. Минимальные бюджеты и ставки меняются, в уроках не фиксируем.
- Перетаскивание — src/components/Sortable.tsx на pointer-событиях (HTML5 drag-and-drop на iOS не работает).

## Награды и недели
- Награды (completeLesson/Boss/Contract/Negotiation/Mission, saveWeeklyReport) выдаёт src/game/engine.ts одной транзакцией (atomic): проверка «был ли результат» и начисление не расходятся при двойном тапе. Окно нового титула показывается после коммита.
- Неделя с negotiationId закрывается только после сыгранного диалога (weekStatus берёт State.negotiations); соперник в rivalCurve для такой недели не получает «типичного босса».
- База v6 один раз очищает прогресс старого курса; бэкап версии 2, старые файлы отклоняются. Импорт бэкапа проверяет версию и структуру ДО очистки базы (validateBackup в src/game/backup.ts).
- Карточки Арсенала и урока: pre с break-words, иначе длинные формулы растягивают страницу на iPhone.
